# Employee Registration and Document Upload System

This assignment uses only the concepts covered in the supplied Chapters 3 and 4.

## Files
- `index.html` — HTML form using POST and multipart file upload.
- `functions.php` — eight required user-defined functions.
- `process.php` — retrieves form data, validates entries, calculates salaries, uploads the document, and displays results.
- `uploads/` — destination folder for uploaded documents.

## Run in XAMPP
1. Copy this folder to `C:\xampp\htdocs\`.
2. Start Apache in XAMPP.
3. Open `http://localhost/Employee_Registration_System/index.html`.
4. Enter sample employee details and choose a document no larger than 2 MB.

## Chapter 3 concepts
User-defined functions, parameters, arguments, return values, conditional statements, default argument value, and `require_once`.

## Chapter 4 concepts
HTML forms, POST, `$_POST`, `$_FILES`, `isset()`, `empty()`, file size, `file_exists()`, `move_uploaded_file()`, and an HTML table for results.

No JavaScript, database, framework, custom arrays, or array-processing loops are used.
